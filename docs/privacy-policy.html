2. Radio Explorer & Directory Legal Position

IMPORTANT LEGAL POSITION

Radio Explorer is an aggregator and index of publicly available internet radio streams. Radio Explorer:

  • Does NOT host radio audio streams or media files.
  • Does NOT relay or re-transmit broadcast streams.
  • Does NOT rebroadcast content.
  • Does NOT operate media servers, streaming servers, or content delivery networks (CDNs).
  • Does NOT alter or modify station audio broadcasts or stream payloads.
  • Does NOT own or claim copyright over station content, logos, or broadcasts.
  • Does NOT guarantee stream availability, uptime, or broadcasting schedule.

Radio Explorer purely aggregates publicly available station metadata and stream URLs obtained from public directories (including Radio Browser). When a user initiates audio playback for any station, the audio stream is requested and delivered directly from the station owner's server or stream provider to the user's local device.

Users may alternatively copy or export stream URLs to compatible third-party media players where permitted by local regulations.

3. Privacy Policy & Data Collection

OmniToolkit is designed with strict privacy-first principles. We operate a zero-telemetry, zero-tracking architecture:

  • No Account Required: You do not need to register, log in, or provide personal information to use OmniToolkit.
  • No Analytics or Tracking: We do not track user behavior, usage patterns, session durations, or module interaction history.
  • No Advertisements: OmniToolkit contains zero commercial advertising networks, SDKs, or promotional tracking scripts.
  • No Cloud Storage: All user-generated data (such as Calendar notes, saved station Favorites, and customized settings) is stored 100% locally on your device via SQLite and local storage.

4. Location Services & Lookup Modules

4.1 Location Services

OmniToolkit does NOT require, request, or track browser or device GPS location permissions. Station playback and location lookup features operate completely independent of device geolocation APIs.

4.2 US ZIP, City, County, & Area Code Lookup

The US Location & Area Code Lookup module operates 100% offline using bundled local datasets (curated US ZIP records and NANPA area code data). Searches for ZIP codes, ZIP+4 inputs, city names, counties, and area codes are executed locally against an offline in-memory/SQLite database with zero external HTTP API calls, third-party requests, or location tracking.

5. Diagnostics & Session Memory

  • Local Diagnostics: Console logs and error messages generated during runtime (such as audio buffering timeouts or stream format checks) remain local to your browser/device for troubleshooting purposes and are never transmitted to external servers.
  • Password Generator: Password generation runs locally using cryptographically secure random number generators (`Random.secure()`). Password history is stored strictly in volatile session memory (RAM) and is immediately wiped when the module is closed or reloaded. Passwords are never saved to persistent storage or external servers.
  • Calculator Session Memory: Calculation history is stored in session RAM during active use and is wiped upon pressing clear (AC) or re-launching the application.
